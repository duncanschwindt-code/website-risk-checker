## [1.0.0] - 2026-07-30

### Added

- Next.js, TypeScript, Tailwind CSS application with accessible responsive pages.
- Live and strictly separated demonstration modes.
- Google Safe Browsing v5, URLhaus, PhishTank, OTX, and VirusTotal lookup-only adapters.
- Dated provider-compliance metadata with noncommercial safeguards.
- URL redaction, public-address validation, DNS rechecks, destination pinning, redirect validation,
  timeouts, and response-size limits.
- Transparent scoring methodology version 1.0.0 and weak-signal cap.
- Device-only result storage and private correction-reference workflow.
- Vitest unit/integration suite, Playwright accessibility/E2E tests, and local mocked fixtures.
- Docker and Docker Compose configuration.
- GitHub CI, CodeQL, dependency review, secret scan, Dependabot, issue templates, and pull-request
  template.
- Legal, privacy, security, contribution, and deployment drafts.
